Vite

Vite появился в 2020 году и развивается под руководством Эвана Ю. Инструмент состоит из двух частей: сервера разработки и сборки для продакшна. Для работы нужен Node.js.

В режиме разработки Vite не собирает единый бандл. Он отдаёт модули браузеру как есть, а сторонние зависимости заранее объединяет в один модуль сборщиком Rolldown.

Сервер разработки и горячая замена

Браузер загружает модули через нативные ES-модули, поэтому сервер запускается быстро даже в крупных проектах. При изменении файла Vite обновляет только затронутый модуль, не перезагружая страницу целиком. Такой режим называют горячей заменой модулей (HMR).

Сборка для продакшна

Для продакшн-сборки используется Rolldown. Он объединяет модули, минифицирует код и подготавливает ресурсы. Команда vite build создаёт каталог dist, а vite preview показывает собранную версию локально.

Настройка

Параметры сборки хранятся в файле vite.config.js. Файл не обязателен: проект работает и со стандартными настройками. 

import { defineConfig } from "vite";

export default defineConfig({
  server: {
    port: 5173
  }
});

Переменные окружения

Переменные, доступные клиентскому коду, должны начинаться с префикса VITE_. Их объявляют в файлах .env, а в коде читают через import.meta.env. Переменные без этого префикса в браузер не попадают.

Требования

Vite работает на Node.js, минимальную версию указывают в документации к выпуску. Пакет устанавливают через npm. Для проектов на React, Vue и других фреймворках есть готовые шаблоны.
