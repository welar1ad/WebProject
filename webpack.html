Webpack

Webpack - сборщик модулей для JavaScript. Проект появился в 2012 году, распространяется под лицензией MIT и работает на Node.js. Сборка начинается с одного или нескольких входных файлов: Webpack проходит по импортам, строит граф зависимостей и формирует выходные файлы.

Точка входа и выход

Входные файлы задают в поле entry, а каталог и имена результатов - в output. По умолчанию готовые файлы складываются в каталог dist. Файл webpack.config.js: 

module.exports = {
  entry: "./src/index.js",
  output: {
    filename: "main.js",
    path: __dirname + "/dist"
  }
};

Загрузчики

Сам по себе Webpack понимает только JavaScript и JSON. Загрузчики учат его работать с другими типами файлов: css-loader разбирает CSS, sass-loader компилирует SCSS, babel-loader переводит современный синтаксис JavaScript в совместимый с браузерами. Загрузчик указывают для конкретного расширения, и он применяется к файлу по ходу сборки.

Плагины

Плагины работают со всей сборкой, а не с отдельными файлами. HtmlWebpackPlugin создаёт HTML-страницу и подставляет в неё собранные скрипты, MiniCssExtractPlugin выносит стили в отдельный файл, DefinePlugin подставляет значения на этапе сборки.

Разделение кода

Большой единый бандл загружается дольше, поэтому Webpack умеет делить код. Динамический импорт import() подгружает модуль по требованию, а оптимизация splitChunks выносит общие зависимости в отдельный файл, который кэшируется браузером.

Разработка и продакшн

В режиме development Webpack не минифицирует код и добавляет карты исходников, а webpack-dev-server обновляет страницу при изменениях. В режиме production включаются минификация и другие оптимизации. Режим задают флагом mode или в конфигурации.

Требования

Webpack запускается на Node.js, конкретную минимальную версию указывают в документации к выпуску. Установка и запуск обычно выполняются через npm или другой менеджер пакетов.
