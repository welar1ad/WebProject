Гайды

Ниже три примера: как создать проект на Vite, как настроить Webpack для работы со стилями и как оптимизировать изображения в Gulp. Команды выполняются в терминале из каталога проекта.

Быстрый старт на Vite

Сначала нужен установленный Node.js. Затем проект создаётся одной командой, которая загружает шаблон: 

npm create vite@latest my-app
cd my-app
npm install
npm run dev

Последняя команда запускает сервер разработки. После изменения файлов страница обновляется автоматически, а адрес сервера выводится в терминале.

Webpack для CSS

Устанавливаем сам сборщик и загрузчики для стилей: 

npm install --save-dev webpack webpack-cli style-loader css-loader

Затем описываем правило: файлы с расширением .css проходят через два загрузчика. 

module.exports = {
  module: {
    rules: [
      { test: /\.css$/, use: ["style-loader", "css-loader"] }
    ]
  }
};

Загрузчики применяются по цепочке справа налево: css-loader разбирает импорты в CSS, а style-loader встраивает стили на страницу.

Оптимизация изображений в Gulp

Для сжатия изображений подключаем плагин imagemin и описываем задачу. 

const { src, dest } = require("gulp");
const imagemin = require("gulp-imagemin");

exports.images = function () {
  return src("src/images/*")
    .pipe(imagemin())
    .pipe(dest("dist/images"));
};

Запуск задачи: npx gulp images. Обработанные файлы появятся в каталоге dist/images.
