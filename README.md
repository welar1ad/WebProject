## Что это за проект

Учебный статический сайт о сборщиках фронтенд-проектов: Webpack, Vite и Gulp.
Описаны назначение инструментов, их возможности, сравнение, примеры настройки и видеоуроки.

## Технологии

- HTML5
- CSS3
- Concise CSS (подключён через CDN)
- шрифт JetBrains Mono (локальные файлы woff2)
- нативный JavaScript для мобильного меню

Проект не требует сборки и серверной части.
