Gulp

Gulp — таск-раннер на Node.js. Он не собирает модули, а выполняет задачи над файлами проекта. Задачи описывают в файле gulpfile.js, а дополнительные возможности подключают плагинами.

В основе лежат потоки Node.js. Задача читает файлы через src, прогоняет их через цепочку обработчиков и записывает результат через dest.

Задачи и потоки

Каждая задача — это функция, которая возвращает поток. Между собой задачи связывают методами series (последовательно) и parallel (параллельно). Готовые задачи экспортируют, и после этого их можно запускать из командной строки одной командой.

Основные методы

src задаёт исходные файлы, dest — каталог результата, pipe передаёт поток следующему обработчику, watch следит за изменениями. Пример конвейера для стилей: 

const { src, dest, watch, series } = require("gulp");
const sass = require("gulp-sass")(require("sass"));

function styles() {
  return src("src/scss/*.scss")
    .pipe(sass())
    .pipe(dest("dist/css"));
}

exports.build = series(styles);
exports.dev = function () {
  watch("src/scss/*.scss", styles);
};

Плагины

Плагин выполняет одну конкретную операцию: gulp-sass компилирует SCSS, gulp-csso минифицирует CSS, gulp-uglify сжимает JavaScript, gulp-imagemin оптимизирует изображения. Большинство плагинов работают как звенья одной цепочки pipe.

Где применяется

Gulp удобен, когда нужно обработать набор готовых файлов: собрать стили, подготовить изображения, скопировать шрифты и статику. Для приложений с модулями чаще берут сборщики вроде Webpack или Vite. Оба подхода можно совмещать: Gulp запускает общие задачи, а модули собирает отдельный инструмент.
